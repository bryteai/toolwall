## How to be listed

1. Open a pull request against `main` that adds value to the
   project under Apache-2.0 (see `CONTRIBUTING.md` for the kinds
   of contributions explicitly welcomed at v0.1.0).
2. On merge, the maintainer appends your line to the contributors
   block above. Format:
   `- **Your Name** — short description of the contribution (#PR)`.
3. The DCO sign-off (`Signed-off-by:` line in commit messages) is
   required for non-trivial contributions. See `CONTRIBUTING.md`.
